# Some info on paradigms
### Imperative programming
- An imperative program consists of commands for the computer to perform.
##### Procedural programming
- a type of imperative prog in which the program is built from one or more procedures (also termed subroutines or functions)

> "Procedural programming could be considered a step toward declarative programming. A programmer can often tell, simply by looking at the names, arguments, and return types of procedures (and related comments), what a particular procedure is supposed to do, without necessarily looking at the details of how it achieves its result. At the same time, a complete program is still imperative since it fixes the statements to be executed and their order of execution to a large extent"

### Declarative
- In contrast with imperative prog, declarative programming expresses the logic of a computation without describing its control flow.
- Functional programming is a substyle of this

##### Functional programming

* A declarative style where computation is expressed as evaluation of pure functions.
* Encourages immutability, recursion, and composability.

### Logic programming

* Programs are written as facts and rules.
* The system derives answers via logical inference.
* Example: Prolog.
