> "If one function calls another, they should be vertically close, and the caller should be above the callee, if at all possible. This gives the program a natural flow."

###### Vertical ordering
> "In general we want function call dependencies to point in the downward direction. That is,
a function that is called should be below a function that does the calling. This is the exact
opposite of languages like Pascal, C, and C++ that enforce functions to be defined, or
at least declared, before they are used. "
